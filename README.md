# Dodge the Creeps

A small 2D game built with Godot 4 by following the official
["Your first 2D game"](https://docs.godotengine.org/en/stable/getting_started/first_2d_game/index.html)
tutorial.

Open the folder with the Godot editor (4.x) and press F5.

Art, music and font are the tutorial's assets (see `LICENSE-assets.txt` and `fonts/LICENSE.txt`).

## Controls

| Action | Keys |
| --- | --- |
| Move | WASD, arrow keys, D-pad or left stick |
| Start / restart | Start button, <kbd>Enter</kbd> or <kbd>Space</kbd> |

## Sharing the finished game

1. Install export templates: **Editor > Manage Export Templates**.
2. **Project > Export...**, add a preset for your platform (Windows, Linux, macOS, Web, Android...).
3. Click **Export Project** and pick a destination.

`export_presets.cfg` is git-ignored because it can contain machine-specific paths and signing credentials.
